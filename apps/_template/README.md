# <app>

Template for a new app. Copy this folder to `apps/<app>/` and fill in.

- **What it is**: one sentence.
- **Repo**: link to the app's source repo.
- **Domains**: staging and prod.
- **Database**: none, or CNPG cluster name.
- **Secrets**: list of `<app>_<purpose>` keys in Bitwarden (Staging and Prod).

`base/` and `overlays/` are added in Phase 10 with the app pipeline.
